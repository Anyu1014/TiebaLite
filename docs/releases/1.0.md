# TiebaLite 1.0

版本1.0，构建61。源码位于 `Anyu1014/TiebaLite` 的 `1.0` 分支。

- iOS 26/27 使用系统原生TabView标签栏，支持系统液态玻璃及拖动切换；较旧系统使用兼容悬浮栏。
- Android使用统一布局与Anyu磨砂效果，评论区新增头像/等级/点赞数、日期地区及灰色楼中楼预览。
- 列表和回复触底自动追加，顶部下拉手动刷新；底栏切回首页保留已加载内容及滚动位置。
- 关于页更新为TiebaLite、1.0、Anyu，源码入口链接本仓库；项目代码保持GPL-3.0-only，完整版权与第三方许可保留。

## 下载

- `TiebaLite-1.0.apk`：本地固定密钥签名的Android Release，最低Android8（API26）。
- `TiebaLite-1.0-unsigned.ipa`：iOS Release归档的未签名包，最低iOS16.4；安装前须为主应用和Open In扩展正确签名。
- `TiebaLite-1.0-source.zip`：对应提交的双端完整源码、协议、资源、许可及构建脚本。
- `release-manifest.json` 与 `SHA256SUMS`：对应提交、工具及校验信息。

开发签名IPA仅在本机保存，用于已登记的用户设备；公开发行不附带用户设备描述文件。请按安装包实际签名类型安装，不要通过卸载已有应用来解决签名冲突。

## 验证与限制

共享配置测试3项；Android JVM单测23项、另1项默认线上测试跳过，Release构建与Lint通过。原生设备测试覆盖关于页、许可正文、首页返回、顶部下拉和触底追加。iOS应用/测试目标编译、Release归档及开发签名分别验证；在已登记iPhone上验证1.0/build61原位安装和启动，持久化数据校验不变；原生标签栏拖动UITest已添加，本机无模拟器运行时，未执行该UITest。签名和真机安装/启动记录存放在本机，不公开设备标识及备份。

未验证所有登录账号写操作、Android系统/厂商矩阵、iOS26与27所有交互。原生液态玻璃的最终手感由对应系统实现。
