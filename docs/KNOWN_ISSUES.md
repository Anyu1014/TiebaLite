# 已知问题与边界

- iOS缺少本机模拟器运行时；未执行测试套件或安装启动。IPA未签名，现有profile不匹配新主应用和扩展ID。签名并运行验收后才能判断设备行为。
- 登录、风控、消息、社交与写操作没有真实账号验收；源码/fixture通过不能保证百度接受请求。发帖和资料编辑沿用非官方实验接口；未知发送结果保留草稿，不自动重发。
- Android不是SwiftUI像素复刻，未包含全部iOS手势与动画。图片可缩放、尚无平移；平板、字体、暗色、无障碍及音视频/系统媒体保存尚未完成设备矩阵验收。
- Android与iOS备份格式不同；Android备份不含凭据/草稿/字体/媒体，且有8MiB上限。离线抓取期间若服务端删除/隐藏内容或分页变化，会明确失败并保留原快照，不能保证抓取任意大帖。
- Android本地Release密钥只在本机`.build/signing`保存，未发布且不在源码包。未来升级必须保留相同签名；当前Debug包使用另一签名。
- Android Lint剩余非阻断建议包含依赖新版本提示、KTX写法、旧图标API与monochrome图标缺失；未为此升级依赖或替换用户图标。详见本次报告。
- GPL与依赖材料保留，但图标/原截图/百度动态内容的完整权属、商标同名及外部服务条款未完成独立核实。本任务未作上架保证，也未新增“禁止商用”等限制。
- 右侧双端预览是静态对照页；iOS是原项目参考，Android是模拟器截图，无法在网页里执行原生账号操作。
